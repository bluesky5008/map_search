# map_search — 월드맵 토지정보 추출기

게임 **"삼국지-전략판"** PC 클라이언트의 월드맵 전 좌표를 자동 순회하며 좌표별 토지 정보를 추출해 파일로 저장하는 stand-alone Windows 도구입니다. 게임이 좌표별 토지 데이터를 외부로 제공하지 않으므로, 화면 캡처·이미지 인식·UI 자동 조작으로 정보를 수집합니다.

> **상태:** 요구사항·설계 기준선 v1 승인 (2026-08-01). 구현 착수 전.

## 수집하는 정보

좌표(0,0 ~ 자동 감지된 맵 최대치, 최대 <2000×2000)별로 다음을 수집합니다. **순수 토지 정보만 수집하며** 도적 정보, 점령자 이름 등은 수집하지 않습니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 토지 대분류 | 자원토지 / 1칸건물 / 2칸이상건물 / 이동불가지역 | |
| 세부 종류 | 공터, 목재, 철광, 석재, 식량, 구리 광산 / 망루, 울타리, 막사, 조폐창, 공방, 장군 막사, 창고, 악부, 요새(+미상) / 주성, 분성, 성지, 부두, 군진, 공정영 / 강, 산 | |
| 자원 레벨 | 목재·철광·석재·식량 Lv1~10, 구리 Lv6~10 | 클릭 모드(MODE-B/C)에서만 |
| 점령상태 | 내땅·동맹원땅·우호동맹땅·적군땅·중립 | 타일 테두리 색상 판별 |
| 2칸이상 건물 중심좌표 | 건물 점유 좌표들을 하나로 묶은 대표 좌표 | MODE-A에서는 추정값 표기 |
| 수집 시각 | 좌표별 ISO8601 | 스캔 결과는 시점 스냅샷 |

## 스캔 모드

| 모드 | 방식 | 수집 정보 | 1600×1600 예상 소요 | 구현 |
|---|---|---|---|---|
| **MODE-A** | 화면인식 전체 스캔 (클릭 없음) | 대분류·자원 종류·점령상태 | 약 4.5~9.5시간 | **v1** |
| MODE-B | 하이브리드 (전체 화면인식 + 선별 클릭) | MODE-A + 선별 대상의 레벨 | MODE-A + 클릭 수 × ~0.7초 | 후속 |
| MODE-C | 영역 한정 전수 클릭 | 전 항목 (레벨 포함) | 100×100 영역당 약 2~3시간 | 후속 |

전 좌표 클릭 방식은 맵 전체 기준 주 단위(1600×1600에서 15~30일)가 걸려 지원하지 않습니다. 이것이 모드를 분리한 이유입니다.

## 동작 방식

```text
좌표 점프(지도 모드 → 좌표 입력 → 이동) → 화면 안정화 대기 → 캡처
  → 등각 그리드 분할 → 타일 분류(템플릿 매칭 + 색상 판별) → SQLite 기록
  → 완료 시 CSV 내보내기
```

- **백그라운드 동작:** 게임 창이 다른 창에 가려져 있어도 스캔이 진행됩니다(Windows Graphics Capture + PostMessage). 클라이언트가 이를 지원하지 않으면 전면 제어 모드로 폴백합니다. 창 **최소화**는 지원하지 않습니다.
- **맵 크기 자동 감지:** 좌표 입력란에 9999를 넣으면 실제 최대 좌표로 강제 변경되는 게임 동작을 이용합니다.
- **중단/재개:** 수집은 SQLite에 좌표 단위로 멱등 기록되며, 강제 종료 후 재시작하면 체크포인트에서 이어서 스캔합니다.
- **이상 복구:** 예기치 못한 게임 팝업·화면 전환 실패를 감지하면 복구를 시도하고, 불가하면 체크포인트를 남기고 안전하게 정지합니다.
- **보수적 분류:** 인식 신뢰도가 낮은 타일은 오분류 대신 `미상`으로 기록하고 증거 이미지를 남깁니다(분류 정확도 목표 99%).

## 산출물

- **SQLite** (`*.db`) — 수집 원장. `scans`(스캔 메타·체크포인트), `tiles`(좌표별 레코드, PK=(scan_id,x,y)).
- **CSV** (`scan_<id>_<날짜>.csv`, UTF-8 BOM) — 완료 시 내보내기. 100만 행 단위 분할 옵션(엑셀 호환).

```text
x,y,category,kind,level,occupancy,center_x,center_y,center_estimated,confidence,status,captured_at
```

## 요구 환경

- Windows PC (Windows 11 기준), 디스플레이 배율 100%
- "삼국지-전략판" PC 클라이언트가 **1282×752 창 크기**로 실행·로그인된 상태
- 네트워크 통신 없음, 게임 메모리 접근·패킷 분석 없음 — 화면에 표시되는 정보만 읽습니다

## 설치·실행 (예정)

구현 완료 후 확정됩니다. 계획: Python 3.12 + OpenCV, PyInstaller 단일 exe 배포.

```powershell
# 계획 중인 사용 형태 (구현 후 확정)
mapscan --mode A --out .\output\        # 전체 화면인식 스캔
mapscan --resume                        # 마지막 체크포인트에서 재개
mapscan --export-csv --split-rows 1000000
```

## 로드맵

1. **v1 (다음 단계):** 기술 검증 스파이크 4건(백그라운드 캡처·입력, 광역 줌 자원 식별, 좌표 숫자 판독, 팝업 오클루전) → MODE-A 구현 → 실기 검증

3. **이후:** 안드로이드 환경 프로그램 (인식 로직은 캡처·입력 인터페이스와 분리되어 재사용 대비)

## 주의사항

- 스캔 결과는 **스캔 시점의 스냅샷**입니다. 점령 상태 등은 스캔 중에도 계속 변합니다.
- 게임 클라이언트 업데이트로 UI·그래픽이 바뀌면 템플릿 재캘리브레이션이 필요할 수 있습니다.
- 화면 자동 조작 도구이므로 게임 이용약관과의 관계는 사용자 본인의 책임입니다. 본 도구는 정보 열람 목적의 조작(화면 이동)만 수행하며 점령·행군 등 게임 행위는 하지 않습니다.

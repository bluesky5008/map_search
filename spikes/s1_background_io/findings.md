## 창 선택(동일 제목 2개) — **제목 매칭 불가 판정**

- `windows-capture`의 `window_name` 매칭은 **z순서에 따라 다른 창을 선택**한다.
  증거: 동일 명령이 시점에 따라 컬러단장용스 화면(`cap_wgc_id.png`)과 羊커리 화면(`click_after.png`)을 반환. 그 사이 `EnumWindows` 순서가 393996 우선 → 328668 우선으로 역전됨.
- `SetWindowText`로 제목을 바꿔 고정하는 방법은 **불가** — 게임이 제목을 즉시 원복시킴.
- **제품 결정 사항:** 캡처는 HWND 기반으로 바인딩해야 한다(winsdk의 GraphicsCaptureItem interop 등). `windows-capture`의 제목 매칭은 다중 클라이언트 환경에서 사용 불가. → T9(win 계층) 구현에 반영.

## S-1b 백그라운드 입력(PostMessage) — **성공 (관리자 권한 필요)**

- 2026-08-01 23:58 재검증 성공. 절차: 관리자 권한 헬퍼(`s1b_elevated.py`, UAC 승인) → `SetWindowPos` z-raise 성공(rc=1) → WGC 세션 바인딩 → 마젠타 오버레이로 창2 완전 가림 → 클라이언트 좌표 (899,588)에 PostMessage 클릭(rc=1,1,1) → 1초 후 프레임에 **타일 팝업("Lv.5 목재, 병주-태원군 (353,330)") 등장 확인**.
- 증거: `evidence/before2.png`(팝업 없음) → `evidence/after2.png`(팝업 등장), `evidence/screen_during_click.png`(클릭 순간 화면 = 마젠타), `evidence/status.txt`.
- **결론: 게임 창이 완전히 가려진 상태에서 캡처와 클릭이 모두 동작한다. 단, 도구를 관리자 권한으로 실행해야 한다(게임이 elevated인 환경).**
- 부수 확인: 클릭 (899,588) → 타일 좌표 (353,330) — 그리드 캘리브레이션(S-2/P-05)용 데이터 포인트 1건 확보.

## (기록) 1차 시도의 차단 경위 — 해결됨

- **게임 프로세스 2개 모두 관리자 권한(elevated)으로 실행 중**, 도구는 일반 권한 → UIPI가 `PostMessage`(error 5 ACCESS_DENIED)와 `SetWindowPos`(rc=0)를 차단한다.
- 따라서 1차로 창1(393996)에 보낸 클릭은 **전달되지 않았음이 확인됨** (당시 반환값 미확인은 프로세스 과실 — 이후 use_last_error로 검증). 사용자 부대 배치 화면은 영향 없음.
- 관리자 권한 헬퍼(`s1b_elevated.py`) 실행을 시도했으나 **사용자가 UAC 승인을 거부** → S-1b는 보류.
- **제품 제약(확정):** 게임이 관리자 권한으로 실행되는 환경에서는 입력·창 조작을 위해 도구도 관리자 권한으로 실행해야 한다. WGC 캡처는 권한과 무관하게 동작한다.
- **재시도 조건(택1):** ① 도구를 관리자 권한으로 실행(UAC 승인), 또는 ② 게임을 일반 권한으로 재실행.

## 추가 발견 — 창 크기 가변

- 사용자가 창1을 리사이즈함(클라이언트 2558x664 관찰). 고정 크기(1278x719) 가정은 실행 전 검증이 필요하며, 제품 시작 시 창 크기를 확인하고 다르면 (권한 확보 후) `SetWindowPos`로 재설정하거나 사용자에게 안내한다. → T9 WindowSession 요구에 반영.

## 최종 판정

**S-1 통과.** ADR-002(WGC + PostMessage 백그라운드 방식) 유지 확정. 전면 폴백 불필요.

제품 구현(T9)에 반영할 사항:
1. 도구는 관리자 권한으로 실행한다(매니페스트/실행 안내). 시작 시 권한·게임 elevation을 점검하고 불일치 시 안내한다.
2. 캡처 세션은 대상 HWND를 z-raise한 직후 바인딩하고, 첫 프레임으로 대상 창 검증을 수행한다(동일 제목 다중 창 대응).
3. 시작 시 창 크기(클라이언트 1278x719)를 검증하고 다르면 SetWindowPos로 재설정한다.
4. 입력 좌표는 클라이언트 좌표계, WGC 프레임은 창 전체(타이틀바 포함 1280x751) — 오프셋 (+1,+32) 변환 일원화.

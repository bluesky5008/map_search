# 템플릿 자산

vision 계층(TileClassifier, DigitReader)이 사용하는 템플릿. 게임 업데이트로
렌더링이 바뀌면 아래 출처 정보로 재수집한다(위험 R-03).

## tiles/ — 타일 스프라이트 (표준 스캔 창 기준)

크기 기준: 클라이언트 2544x657(우상단 사분면 스냅), 디테일 줌 최대 축소.
다른 창 크기·줌에서는 재수집이 필요하다(R-08). 파일명(ASCII) → 분류 매핑은
`mapscan.vision.classifier.TEMPLATE_KINDS`.

| 파일 | (category, kind) | 출처 |
|---|---|---|
| wood.png | resource, 목재 | `spikes/s2_zoom_grid/work3/snap_tr_base.png`의 타일 (1020,620) 중심 96x64 크롭. 같은 뷰의 `snap_click_R.png` 팝업 "Lv.1 목재 (1020,620)"으로 지상 진실 확정 |

**미확보(실기 수집 필요, T14 계획):** 석재·철광·식량·구리(스캔 창 크기),
1칸·2칸 건물 종류별, 그리고 **점령형 스프라이트 전반** — 점령된 자원 타일은
중립형과 달리 생산 시설(밭·목장 등)로 렌더링됨을 확인했다.

## digits/ — 숫자 글리프

팝업 좌표 문자열의 크림색 텍스트(HSV S<90, V≥170)에서 추출. 렌더링(창
크기·계절 테마)에 따라 안티에일리어싱이 달라 교차 소스 매칭이 약하므로,
문자당 소스별 변형(`6.png`, `6_2.png`, ...)을 저장하고 매칭 시 최대 점수를
취한다. 파일명 `comma`/`paren_l`/`paren_r`은 `,`/`(`/`)`.

| 소스 | 스트립 사각형 (x0,y0,x1,y1) | 문자열 |
|---|---|---|
| `spikes/s2_zoom_grid/work3/snap_click_R.png` | (2100,210,2220,236) | `(1020,620)` |
| `image/9목재-내땅.png` | (600,243,710,268) | `(989,645)` |
| `image/3목재-동맹땅.png` | (575,338,690,364) | `(990,647)` |
| `image/7목재-적군.png` | (600,236,722,262) | `(1032,663)` |

추출 절차: 스트립을 위 마스크로 이진화 → 연결 성분을 x 구간 겹침/맞닿음
기준으로 글리프로 병합 → 왼쪽부터 기대 문자열과 짝지어 저장(같은 소스의 중복
문자는 첫 것만). `tests/test_vision_digits.py`가 같은 스트립으로 판독을 검증한다.

**미확보:** 좌표 입력란(맵 모드) 폰트 — S-3(T12 실기)에서 수집·검증.

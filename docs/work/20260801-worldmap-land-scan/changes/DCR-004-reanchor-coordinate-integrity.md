## 변경 사유와 증거

T13 잔존 문제(중앙부 간헐 TrackLost)의 원인을 규명하는 과정에서, 기각 규칙
문제(수정 완료)보다 중대한 **추측항법 좌표 드리프트**를 발견했다.

1. **기저의 지역 의존(F3)**: 격자 기저 E_MX/E_MY의 y-성분이 맵 지역에 따라
   미세하게 달라(u-스텝당 c-방향 \~2.5px), 행 이동 중 좌표 기록이 팬당
   my +1.3\~1.7타일씩 어긋난다. 행 150에서 10팬 후 클릭 지상 진실과 대조한
   실측 오차는 **(mx +2..+11, my −11..−21)타일**이다. 한 화면 안에서는
   ±1타일로 정확하므로 T11\~T13의 국소 검증으로는 드러나지 않았다.
2. **이동장 시차 계단(F2)**: dx(y)가 지형 고도(시차 레이어)로 \~±100px 계단
   불연속 — 3밴드 선형 전단 적합의 기울기가 진동하고 추적 오차가 추가된다.
3. **수면 애니메이션(F4)**: 강 지역은 추적 저점수·안정화 불가(경미 수정 반영).

설계 v3의 "행 시작 1회 재앵커 + 행 내 추측항법"은 이 오차원 때문에 좌표
무결성(기록 정확성)이 성립하지 않는다. 행 길이 제한이나 기각 규칙 개선으로는
해결되지 않는다(팬 1회 안에서도 1\~2타일 발생).

**파일럿 실증(F8)**: 3팬마다 뷰 중앙 대역 예측 타일을 클릭해 팝업 좌표
판독 + 선택 링으로 재앵커한 결과, 사이클당 드리프트 (−1..−2, +4..+5)타일을
정확히 흡수했고, TrackLost 팬의 변위 유실(+11 mx)도 다음 사이클에서 절대
좌표로 복구됐다. 재앵커 적용 시 잔여 오차 ≤1타일, 미적용 사이클은 해당
사이클 드리프트만 남는다.

## 제안 설계 변경 (v4, §4.3 보강)

| 항목 | 기존 (v3) | 변경 | 근거 |
|---|---|---|---|
| §4.3 행 루프 | 행 시작 점프 1회 재앵커, 행 내 추측항법 | **K=3팬마다 클릭 재앵커**: 뷰 중앙 대역의 **평지(resource) 분류 셀** 클릭(절벽·산은 고도 시차 피킹 — 구현 중 실측 반영) → 팝업 좌표 판독(슬라이드 최빈값 투표, 새니티 창: 2+3·경과팬+15·유실팬 타일) + 선택 링(폴백: 클릭점) → 그리드 재앵커·전단 누적 리셋 | F3·F8 |
| §4.3 기록 | 분류 즉시 upsert | **지연 기록**: 레코드를 재앵커 사이클 단위로 버퍼링, 재앵커에서 실측 드리프트를 팬별 선형 보간해 좌표 보정 후 upsert. 잔여 오차 ≤1타일 | F8 |
| §4.3 TrackLost | 행 조기 종료 | 유지하되, **TrackLost 팬의 분류 레코드는 기록하지 않는다**(변위 미상 — 보충 방문 몫). 재앵커 성공 시 행 계속 진행 가능(조기 종료 완화) | F4·F8 |
| §4.3 재앵커 실패 | — | 판독 실패·새니티 위반 시 다음 사이클로 이월(창 확대). **연속 2사이클 실패 시 행 조기 종료**(버퍼 레코드는 마지막 성공 앵커 기준 보정분만 기록) | F7 |
| §4.3 팝업 처리 | 행 시작 프레임만 | 재앵커 클릭 팝업이 다음 팬 프레임에 남는다 — 해당 프레임 분류에서 팝업 사각형 제외(기존 `extra_exclude` 메커니즘 재사용) | S-5 실측 |
| 전제 조건 | — | DigitReader 판독 신뢰성(현재 봄 테마 \~85\~90%) — T14.3 글리프 보강과 오판독 새니티 창을 전제로 명시 | F7 |

이미 반영한 경미 변경(기준선 내 — 보고용): 이중 앵커 기각 규칙(pan.py),
팬 텔레메트리 로그(controller.py), 점프 GO 재클릭·수면 안정화 폴백(navigator.py).

## NFR-02 영향

재앵커 1회 ≈ 1.5\~2s(클릭+정착+판독). K=3이면 팬당 +0.5\~0.7s
(2.95 → 3.5\~3.7s) → 총 소요 33\~36h → **39\~43시간**. 판독 실패 재시도를
감안해도 NFR-02(48시간) 이내다. K는 지정 영역 스캔(T14.7)에서 실측 후
필요시 조정한다(드리프트가 작은 지역은 K를 늘려 상각 가능).

## 대안

| 안 | 내용 | 평가 |
|---|---|---|
| **(권고)** 주기 재앵커 + 지연 기록 | 위 제안. 파일럿으로 실증됨 | 오차 ≤1타일, +3\~7h |
| 행 길이 제한·점프 증가 | 행을 짧게 끊어 점프 재앵커 빈도 증가 | 드리프트가 팬 1회 내에도 1\~2타일 → 근본 해결 불가 |
| 기저 필드 사전 캘리브레이션 | 맵 전역을 지역별로 측량해 기저 테이블化 | 대규모 사전 작업 + 고도 지형 예외 여전 — 과잉 |
| 팬 폐기(점프 단독 복귀) | v2 이전 방식 | 150시간 — NFR-02 재협의 필요, DCR-003 무효화 |

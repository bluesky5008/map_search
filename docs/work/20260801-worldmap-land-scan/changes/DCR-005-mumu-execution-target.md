## 변경 사유와 증거

PC 클라이언트는 **새벽 3시 일괄 로그아웃** 정책이 있어 전체 스캔(외삽
38\~52h)의 무인 완주가 불가하다. 앱(에뮬레이터) 클라이언트는 이 정책이 없다
(게이트 1 — 사용자 보장). 전환 가능성 게이트를 스파이크로 검증했다.

| 게이트 | 판정 | 근거 |
|---|---|---|
| 1. 앱은 3시 로그아웃 없음 | 통과(사용자 보장) | — |
| 2. 게임의 에뮬레이터 허용 | **미검증** — 직접 확인 수단 없음. 스파이크 전 과정 무징후. 운용 중 감시로 갈음(아래 위험) | S-7 |
| 3. 해상도·렌더링 | 통과 — 내부 2544×657@240dpi, 자식 클라이언트 = 내부 해상도(1:1), UI 패치 NCC 0.88\~0.90 @1:1 | 사용자 스크린샷 + S-7 |
| 4. WGC 캡처 + PostMessage 입력 | **통과** — 캡처 top(게임 영역 (1,40)+2544×657), 입력 MuMuNxDevice. 팬 게인·재현성 PC와 동일(좌 -443 σ0/우 +446 σ0/관성 0), 수직 팬·격자 기저 좌표 진실 정합 | S-7 |
| 5. UI 차이 | **통과** — 팝업 구조·글리프 크기 1:1. 오판독은 소스별 변형 3종으로 해소(PC 회귀 11소스 무잠식) | S-7 |

핵심 실측: **현행 도구(WGC·PostMessage·격자·판독·재앵커 설계)가 MuMu에서
그대로 성립한다.** 필요한 것은 소규모 어댑테이션뿐이다.

## 제안 변경

### 실행 환경 (요구사항 실행 전제)

| 항목 | 기존 | 변경 |
|---|---|---|
| 게임 클라이언트 | PC 클라이언트(관리자 권한) | **MuMu 에뮬레이터 안의 앱 클라이언트** (PC 클라이언트는 병행 유지 — 코드 경로 보존, 이번 작업에서 불변) |
| 도구 권한 | 관리자 필수(UAC 러너) | MuMu는 비관리자 — **일반 셸 직접 실행** (PC 경로는 기존 로직 유지: 대상 elevated일 때만 상승 요구) |
| 스캔 창 | `apply_scan_rect`로 사분면 설정·복원 | **MuMu에서는 생략 필수** — 자식 클라이언트 2544×657 = 내부 해상도. 리사이즈 시 스케일링으로 1:1 파괴 |
| 무인 완주 | 3시 로그아웃으로 불성립 | 성립(게이트 1). 잔여 위험은 게이트 2 감시 |

### 도구 적응 (모두 소규모, PC 경로 무영향)

1. **캡처/입력 HWND 분리** — 캡처는 top(Qt), 입력은 MuMuNxDevice.
   controller/CLI 배선에 입력 hwnd 분리 인자 추가.
2. **MuMu 창 발견** — 제목 필터 미검출이므로 Qt top + MuMuNxDevice/nemudisplay
   자식 구조로 판별해 인스턴스명(창 제목)으로 선택(S-7 참조 구현 존재).
3. **`apply_scan_rect` 생략 모드** — 크기 검증(2544×657 확인)만 수행.
4. **글리프 변형 등록** — MuMu 변형 3종(`3_2`, `3_3`, `paren_r_4`)을
   `assets/templates/digits/`에 등록(검증 완료분, 판독 회귀 추가).
5. `client_offset`·`_verify_binding`·격자·재앵커·팬 추적: **무변경 성립 확인됨.**

### 적응 후 실사·측정 (구현 완료 조건)

- UI 상수 차이 실사(팝업 커버·"군사 스킬" 칩·링 검출 신뢰도 — S-7 관찰 5).
- **행 2개 처리율 측정**(measure_k 재사용) → 에뮬레이터 기준 NFR-02 외삽 갱신.
- 다계정 병렬 운용 설계 확정: 행 청크 분할(계정별 행 범위) + DB 병합(별도 DB →
  upsert 병합), 팝업 기하는 최악 케이스(버튼 4 + 아이콘 4) 상수로 통일.
  예측(PC 처리율 기준): 2계정 20\~27h, **4계정 11\~15h**(밤샘 1회 완주선).
